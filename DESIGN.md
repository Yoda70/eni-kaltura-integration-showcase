# SPA design

The SPA is kept as one self-contained HTML file so PageCrypt encrypts markup, styles, JavaScript, and embedded JSON together. Real catalog data will be normalized and embedded during a later build step.

## Required real inputs
- prod142_all_entries_caption_coverage.csv
- prod142_caption_assets_all_versions.csv
- prod142_entries_with_ready_subtitles.csv
- prod142_entries_without_subtitles.csv
- prod142_entries_with_only_non_ready_subtitles.csv
- prod142_catalog_caption_summary.json
- Yellow membership/category export
